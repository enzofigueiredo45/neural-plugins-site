Política de Privacidade

O formulário solicita nome e e-mail apenas para validar o fluxo antes do checkout. Estes dados não são salvos no navegador por este site estático; a conclusão da compra e o envio do produto devem ser feitos pelo provedor de checkout configurado.

Dados de cartão, Pix ou pagamento são processados pelo provedor de checkout escolhido, como Stripe, Mercado Pago, PayPal ou Hotmart. Este site não armazena dados financeiros sensíveis.

Usamos Vercel Web Analytics para medir visitas e páginas acessadas de forma agregada, sem armazenar dados de cartão neste site. Você pode solicitar remoção ou correção dos seus dados pelo canal de suporte oficial informado na loja.
